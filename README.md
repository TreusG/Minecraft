# Minecraft 2D

A simple 2D Minecraft-style game where you can mine blocks, collect resources, and build your own world.

## Play

Play Minecraft 2D

## Features

- Random worlds with trees, caves, hills, and ores
- Mine blocks and collect resources
- Different tools for different blocks
- Place blocks and build
- Generate new worlds anytime
- Pixel-style graphics

## Controls

- `1` \- Axe
- `2` \- Pickaxe
- `3` \- Shovel
- `Esc` \- Clear selection
- Click blocks to mine
- Select an item and click an empty space to place it

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

Or run:

bash

```bash
python -m http.server 8000
```

Open `http://localhost:8000` in your browser.
